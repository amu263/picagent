# PicAgent

**让 AI 生图从灵感到成品，发生在同一个工作台。**

PicAgent 为创作者与小型团队提供完整的 AI 生图工作流：素材管理、提示词组合、作品生成、队列进度、审核与作品资产归档，全部集中在一个清晰、专注的界面中。

## 为什么选择 PicAgent

### 从素材到成品，一条流程
词卡、人设与模板按类别组织，支持缩略图浏览与组合。选好素材、确定模型、写下你的想法，剩下的交给工作流。

### 看得见的进度
每个作品都有明确的队列位置、预计时间与生成状态。不用猜测，也不用反复刷新。

### 属于你的空间
每个账号拥有独立的素材、队列与作品资产。团队协作时，边界清楚，资产不混。

### 作品被认真对待
版本保留、审核记录、作品资产入库与下载，让每一张成品都可追溯、可复用。

### 为移动而设计
适配 Android 手机与平板，支持完整面板、素材浏览、作品查看与下载。

### 安全连接
客户端仅通过 HTTPS 连接，不在界面暴露服务地址、协议或内部配置。

## 开始使用

1. 安装 `PicAgent-1.0.1.apk`（Android 8.0+）。
2. 使用管理员提供的账号登录。
3. 没有账号？向服务管理员获取一次性注册码后注册。
