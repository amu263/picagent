# PicAgent

**让 AI 生图从灵感到成品，发生在同一个工作台。**

PicAgent 为创作者与小型团队提供完整的 AI 生图工作流：素材管理、提示词组合、作品生成、队列进度、审核与作品资产归档，全部集中在一个清晰、专注的界面中。

## 为什么选择 PicAgent

### 从素材到成品，一条流程
词卡、人设与模板按类别组织，支持缩略图浏览与组合。选好素材、确定模型、写下你的想法，剩下的交给工作流。

### 看得见的进度
每个作品都有明确的队列位置、预计时间与生成状态。不用猜测，也不用反复刷新。

### 属于你的空间
每个账号拥有独立的素材、队列与作品资产。团队协作时，边界清楚，资产不混。

### 作品被认真对待
版本保留、审核记录、作品资产入库与下载，让每一张成品都可追溯、可复用。

### 为移动而设计
适配 Android 手机与平板，支持完整面板、素材浏览、作品查看与下载。

### 分享与收藏
- **分享广场**：按词卡分类浏览社区分享，支持匿名或实名投稿。
- **管理员审核**：投稿经审核后发布，确保内容质量。
- **收藏页**：把喜欢的词卡、人设、模板收藏到自己的素材库，随时用于作品工坊。
- **作品资产**：独立浏览自己的作品资产，缩略图浏览，下载原图。

### 自动审查迭代
- review agent 对照参考模板图审核；不符时自动交 worker 重写提示词并重出。
- 审查通过即停止迭代，交用户最终判决。
- Anima 最多自动 5 张，GPT-Image-2 最多 8 张，达到上限才停止。
- 同一用户的历史流程经验只在该用户空间内汇总，用于后续重写判定。

### Anima 双后端
- 作品工坊选择 Anima 时，可指定 **自动 / 本地 ComfyUI / 云端 2x.nz**。
- 条目详情页可中途切换后端并重做，不必重新投递。
- 自动模式本地优先，失败回退 2x。

### 安全连接
客户端仅通过 HTTPS 连接，不在界面暴露服务地址、协议或内部配置。

## 开始使用

1. 安装 `PicAgent-1.0.6.apk`（Android 8.0+）。
2. 使用管理员提供的账号登录。
3. 没有账号？向服务管理员获取一次性注册码后注册。
